# dawnwenhui 个人网站

> AI前端开发者的技术展示网站

## 🚀 快速开始

### 1. 安装依赖
```bash
cd personal-website
npm install
```

### 2. 启动开发服务器
```bash
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000) 查看网站

### 3. 构建生产版本
```bash
npm run build
npm start
```

## 📁 项目结构

```
personal-website/
├── app/
│   ├── globals.css      # 全局样式 + Tailwind
│   ├── layout.tsx       # 根布局
│   └── page.tsx         # 首页
├── public/              # 静态资源
├── package.json
├── tailwind.config.js   # Tailwind 配置
├── tsconfig.json        # TypeScript 配置
└── README.md
```

## 🎨 技术栈

- **框架**: Next.js 14 (App Router)
- **样式**: Tailwind CSS
- **动画**: Framer Motion
- **图标**: Lucide React
- **语言**: TypeScript
